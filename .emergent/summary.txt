**original_problem_statement**: The user wants to build a comprehensive ride-hailing application called NEXRYDE, for the Nigerian market. The core business model is a driver-subscription system (drivers pay a monthly fee and keep 100% of their earnings), which differs from the commission-based model of competitors like Uber and Bolt.

The user has provided extensive feedback throughout the development process, focusing on UI/UX polish, feature parity with apps like inDrive, and specific business logic.

Key requirements implemented and iterated upon include:
- A two-tier driver subscription model:
    1.  **Intra-City Plan (₦18,000):** Allows drivers to operate within any single city in Nigeria (e.g., Lagos to Lagos, Abuja to Abuja).
    2.  **Warrior Pack (₦30,000):** Unlocks all trips, including inter-city travel (e.g., Lagos to Ibadan).
- An inDrive-style booking flow where the rider can adjust the calculated fare. The flow is:
    1.  User enters pickup/destination.
    2.  User clicks Calculate Fare.
    3.  The system uses Google Maps API to calculate a real-time, dynamic price.
    4.  The app displays this price with [+] and [-] buttons, allowing the rider to adjust the offer.
    5.  The rider submits the final offer to nearby drivers by clicking Find Offers.
- A polished, modern, and highly visible UI for the booking screen, inspired by a screenshot of the inDrive app.
- Persistent user login sessions and optional biometric (Fingerprint/Face ID) authentication.
- Removal of all mock/dummy data from the UI to reflect the app's true state (e.g., empty trip history for new users).
- AI-enhanced features for drivers, such as smart trip suggestions and traffic predictions.

**User's preferred language**: English
