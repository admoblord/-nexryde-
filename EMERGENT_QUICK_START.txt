═══════════════════════════════════════════════════════════════
  BACKEND API ENDPOINTS (ALREADY LIVE)
═══════════════════════════════════════════════════════════════

GET  /api/subscription/pricing
     → Returns pricing for both tiers

POST /api/subscription/subscribe/{tier}?driver_id={id}
     → Starts 24h trial for selected tier

GET  /api/subscription/status/{driver_id}
     → Returns current subscription status

POST /api/subscription/upgrade-to-road-warrior/{driver_id}
     → Upgrades City Rider to Road Warrior

POST /api/subscriptions/{driver_id}/submit-payment
     → Submits payment screenshot for verification

GET  /api/route-cache/get-route?pickup_lat=X&pickup_lng=Y&dropoff_lat=A&dropoff_lng=B
     → Gets route (from cache if available, else Google Maps)

GET  /api/route-cache/stats
     → Shows cache hit rate and cost savings

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

ISSUE: Frontend can't connect to backend
FIX: Check EXPO_PUBLIC_BACKEND_URL in frontend/.env
     Use computer IP (not localhost) for physical devices
     Find IP: ipconfig getifaddr en0 (macOS)

ISSUE: Image picker not working
FIX: cd frontend && npm install expo-image-picker
     npx expo start -c

ISSUE: Backend API returns error
FIX: Check if MongoDB is running
     Check GOOGLE_MAPS_API_KEY in backend/.env
     curl http://localhost:8000/health

ISSUE: Pricing not showing
FIX: Verify backend is running
     curl http://localhost:8000/api/subscription/pricing
     Check browser console for errors
